# RISC-V-Assembly-ID-Validation
Created my own ID Validation Toolkit using assembly, as part of a class assignment.

This program takes user input in the form of an ID number and allows the user to complete different operations on the ID in order to validate it. There are five different operations that the user can choose from which include parity, checkSum, reverse, countDigits, and fraudCheck. The program runs on a loop and can check different IDs with different operations until the user wants to exit.

Within this assignment I was able to practice implementing subroutines and different system calls in RARS. It was really good practice to write the subroutines and practice correct calling conventions for assembly code, and of course to practice debugging and fixing any errors I ran into during the process.
